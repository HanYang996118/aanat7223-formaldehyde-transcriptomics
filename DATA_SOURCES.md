# Data sources

All transcriptomic datasets are public GEO records:

| Accession | System | GEO record |
|---|---|---|
| GSE23179 | Rat nasal epithelium; whole-body inhalation | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE23179 |
| GSE42394 | Rat nasal tissue; nose-only inhalation | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE42394 |
| GSE27263 | Controlled-human nasal biopsies | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE27263 |
| GSE21477 | Primary human nasal epithelial cells | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE21477 |

The raw CEL files and full expression matrices are not redistributed in this code archive. Download them from GEO and follow the file/input paths documented in the analysis scripts. Additional intermediate and result archives are supplied separately as journal supplementary materials.
